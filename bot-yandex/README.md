# Бот «Местов.Нет» на Yandex Cloud Functions

Бесплатная serverless-версия (укладывается в free tier Яндекса).

- **webhook** — Telegram шлёт апдейты на публичный URL функции;
- **таймер-триггер** — будит функцию в 13:20 UTC (**16:20 по Крыму**) для рассылки;
- **хранилище** — подписки лежат в Object Storage как JSON-объекты `sub/<id>.json`.

Точка входа: `index.handler`. Зависимость: `boto3` (см. `requirements.txt`).

---

## Что создаём в консоли Яндекса (по порядку)

### 1. Бакет Object Storage
**Object Storage → Создать бакет.** Имя, например, `mestov-bot-data`
(имя глобально уникальное — если занято, придумай другое). Остальное по умолчанию.

### 2. Сервисный аккаунт
**Сервисные аккаунты → Создать.** Имя `mestov-bot-sa`. Назначь ему роли:
- `storage.editor` — чтобы читать/писать подписки в бакет;
- `functions.functionInvoker` — чтобы таймер мог вызывать функцию.

### 3. Статический ключ доступа (для S3)
У сервисного аккаунта `mestov-bot-sa` → **Создать новый ключ → Статический ключ доступа.**
Сохрани **Идентификатор** и **Секретный ключ** — это `AWS_ACCESS_KEY_ID`
и `AWS_SECRET_ACCESS_KEY`.

### 4. Функция
**Cloud Functions → Создать функцию.** Имя `mestov-bot`.
- Среда выполнения: **Python 3.12**.
- Способ: **Редактор кода**. Создай два файла:
  - `index.py` — вставь содержимое из этой папки;
  - `requirements.txt` — одна строка `boto3`.
- **Точка входа:** `index.handler`
- **Таймаут:** 30 сек, **память:** 256 МБ.
- **Сервисный аккаунт:** `mestov-bot-sa`.
- **Переменные окружения:**
  | Ключ | Значение |
  |---|---|
  | `BOT_TOKEN` | токен от @BotFather |
  | `WEBHOOK_SECRET` | `6eQoa4vAL9cnI8cmoJv0nJeZeCi95Mlm` |
  | `ADMIN_ID` | `267459702` |
  | `BUCKET` | имя бакета из шага 1 |
  | `AWS_ACCESS_KEY_ID` | идентификатор ключа из шага 3 |
  | `AWS_SECRET_ACCESS_KEY` | секретный ключ из шага 3 |
- **Создать версию.**

### 5. Сделать функцию публичной
На странице функции → вкладка **Обзор** → включи **«Публичная функция»**.
Скопируй её URL вида `https://functions.yandexcloud.net/<ID функции>`.

### 6. Привязать webhook к Telegram
Выполни один раз (подставь токен, ID функции и тот же секрет):
```bash
curl "https://api.telegram.org/bot<BOT_TOKEN>/setWebhook?url=https://functions.yandexcloud.net/<FUNCTION_ID>&secret_token=6eQoa4vAL9cnI8cmoJv0nJeZeCi95Mlm"
```
Ответ должен быть `{"ok":true,...}`. После этого пиши боту `/start`.

### 7. Таймер-триггер (рассылка по расписанию)
**Cloud Functions → Триггеры → Создать триггер.**
- Тип: **Таймер**.
- **Cron-выражение:** `20 13 ? * * *` (это 13:20 UTC = 16:20 Крым).
- Назначь функцию `mestov-bot` и сервисный аккаунт `mestov-bot-sa`.

Готово. Ежедневные подписчики получают подборку каждый день в 16:20,
еженедельные — в свой день недели.

---

## Проверка

- Webhook стоит: `curl "https://api.telegram.org/bot<BOT_TOKEN>/getWebhookInfo"`
- Логи функции — вкладка **Логи** на странице функции.
- Подписки — объекты `sub/*.json` в бакете.
