# Местов.Нет — инструкции по проекту

## Что это

Агрегатор живой музыки в Крыму. Парсит Telegram-каналы заведений и афиш, извлекает анонсы концертов с помощью Claude (локально через Claude Code), отображает на веб-странице.

---

## Стек

| Компонент | Технология |
|---|---|
| Парсинг источников | Python, `httpx`, `beautifulsoup4` |
| Извлечение событий из текста | Claude (локально через Claude Code) — Ollama не используется |
| Хранение данных | JSON-файлы (`channels.json`, `events.json`, `raw_posts.json`) |
| Фронтенд | Статический `index.html` (vanilla JS + CSS) |

---

## Файлы проекта

```
MestovNet/
├── parser.py           — основной парсер: читает каналы, запрашивает Ollama, пишет events.json
├── fetch_posts.py      — вспомогательный: отдельная загрузка постов
├── channels.json       — список источников (Telegram-каналы)
├── events.json         — результат парсинга (входные данные для фронта)
├── raw_posts.json      — сырые посты до обработки LLM
├── index.html          — веб-интерфейс
├── requirements.txt    — зависимости Python
└── крым_живая_музыка.md — справочник заведений и каналов по городам
```

## Как работает парсинг

1. `parser.py` читает `channels.json` — список каналов с метаданными.
2. Для каждого канала загружает публичную веб-версию `https://t.me/s/<username>`.
3. BeautifulSoup извлекает посты за последние `DAYS_BACK = 14` дней.
4. Каждый пост обрабатывается Claude (локально через Claude Code) — Ollama не используется.
5. Claude возвращает JSON-массив событий или `[]` если анонсов нет.
6. Все события записываются в `events.json` и отображаются в `index.html`.

## Правила работы с источниками

## Запуск

```bash
# Установить зависимости
pip install -r requirements.txt

# Запустить парсинг (нужен запущенный Ollama с моделью llama3.2)
python parser.py

# Открыть интерфейс
open index.html
```

## Возможные проблемы

| Проблема | Причина | Решение |
|---|---|---|
| Telegram отдаёт 429 | Rate limiting | Добавить `time.sleep()` между запросами |
| LLM возвращает не JSON | Галлюцинации llama3.2 | Есть обработка в коде; при необходимости — retry |
| Веб-афиши рендерятся на JS | SPA-архитектура | Использовать `playwright` |
| `t.me/s/` не отдаёт посты | Канал закрытый или удалён | Пометить в `channels.json` как `"active": false` |
