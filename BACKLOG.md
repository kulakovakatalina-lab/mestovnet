## 8. Генерация афиш для площадок (через бота)

Идея: сервис автогенерации афиш-постеров под события — бесплатный/дешёвый инструмент для привлечения новых площадок и мотивации существующих добавлять события самим. Исследование стека — 2026-08-02 (deep-research + верификация, см. диалог); план архитектуры — 2026-08-02.

**Выбранный стек (финализировано 2026-08-02):**
- Фон — **YandexART** через Yandex AI Studio SDK (`pip install yandex-ai-studio-sdk`), решение принято без сравнения с зарубежными моделями — проект уже на Yandex Cloud, единый биллинг, самое простое подключение важнее цены на масштабе пилота (десятки афиш).
  - Официальный прайс подтверждён напрямую с `aistudio.yandex.ru/docs/ru/ai-studio/pricing`: **2,23 ₽ за одну генерацию** (с НДС) — примерно в 5.5 раза дороже Z-Image Turbo/fal.ai, который рассматривался раньше; на объёме пилота (десятки штук) разница не критична.
  - **API асинхронный**: `model.run_deferred(prompt).wait()`, официально «может занимать от пары минут до нескольких часов» — не секунды. UX и архитектура ниже это учитывают.
  - Авторизация — сервисный аккаунт с ролью `ai.imageGeneration.user`, ключ + `folder_id`.
  - Параметры — `width_ratio`/`height_ratio` (не пиксели напрямую) и `seed`; поддержаны несколько взвешенных текстовых фрагментов в одном промпте.
  - **Запросы не идемпотентны на стороне API** — повтор с тем же промптом списывает деньги повторно. Значит идемпотентность (не генерить дважды один `event_id`) обязана быть в нашем коде, не полагаться на API.
  - YandexART логирует промпты пользователей — не передавать в промпт персональные данные (у нас только жанр/тип события, это не проблема, но держать в уме при расширении промпт-билдера).
  - fal.ai/Z-Image Turbo, FLUX.1 schnell, Kandinsky/FusionBrain — рассмотрены и отклонены в пользу простоты; остаются в истории как альтернатива, если YandexART не устроит по качеству или задержке на практике.
- Текст — HTML/CSS-шаблон (`poster.html`) + Playwright screenshot, не Pillow (риск немого фолбэка без libraqm на кириллице) и не Satori (нет системного font fallback).
- Почему не self-hosted GPU: точка безубыточности ~25k изображений/мес, у проекта на порядки меньше; не сейчас.
- Почему не готовые шаблонизаторы (Bannerbear/Placid/Templated): $0.04–0.05 за афишу только за наложение текста — дороже своей связки в 10–30 раз.

**Архитектура (решено 2026-08-02, скорректировано под асинхронность YandexART):** бот (`bot-cloudflare/worker.js`, Cloudflare Worker без Node/браузера) не может сам рендерить Playwright — рендер вынесен в GitHub Actions, job просто блокируется на `.wait()` внутри питоновского SDK (лимит бесплатного раннера — 6 часов, укладывается в официальные «до нескольких часов» с запасом):
```
Админ в Telegram → Worker: выбор события, кнопка «🎨 Афиша»
  → Worker дёргает GitHub Actions (workflow_dispatch, event_id + chat_id)
  → Actions: YandexART (run_deferred + wait) → фон, poster.html+Playwright → текст,
    заливка в тот же Yandex Object Storage bucket, что и сайт,
    Telegram sendPhoto с результатом (Action отвечает сама, без обратного хода через Worker)
```
MVP-скоуп — только `ADMIN_ID` (у площадок пока нет учётной записи в боте, self-serve — отдельная будущая фича, не блокирует эту).
